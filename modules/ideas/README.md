# Ideas

Ideas for new features, one folder each, with what it is, why, and how it could work. An idea that builds on an
existing module goes in that module's `ideas/` instead. When an idea is built it becomes a module
(`modules/<module>/`) with a switch in the registry.

- [style_editor](style_editor/): customise the map on the map itself, every element named, presets per category
  and a colour picker.
- [globe_view](globe_view/): a spinnable globe when zoomed all the way out.
- [apk_builder](apk_builder/): an APK built with your saved settings as defaults, reproducibly.

In modules: [look](../look/ideas/) (more looks, road presets), [logos](../logos/ideas/) (more logo sources),
[typography](../typography/ideas/) (your own fonts).
